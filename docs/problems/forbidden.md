# Acesso negado

- Status HTTP: 403
- Tipo: `https://github.com/miguelsanzbr/radar-licitacoes/blob/main/docs/problems/forbidden.md`

## Quando acontece

O usuário está autenticado, mas não tem o papel que a rota exige (`supplier` ou `operator`).

## O que fazer

Peça o papel ao administrador ou use outra conta.
