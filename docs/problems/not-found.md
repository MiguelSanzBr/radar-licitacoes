# Não encontrado

- Status HTTP: 404
- Tipo: `https://github.com/miguelsanzbr/radar-licitacoes/blob/main/docs/problems/not-found.md`

## Quando acontece

O identificador não existe ou pertence a outro usuário. Para buscas salvas, o recurso de outro usuário também responde 404, para não revelar que ele existe.

## O que fazer

Confira o identificador. Para licitações, use o `id` devolvido pela busca.
